# 04_Webアプリ機能要件

## 1. 文書の目的
本書は Web アプリの画面機能、入力要件、画面遷移、エラー動作を定義する。
用語は 99_用語集 に従う。

## 2. 共通要件
1. ログイン済みユーザーのみ機能画面へアクセス可能とする。
2. 画面共通でヘッダー、グローバルナビゲーション、フッターを表示する。
3. 未認証時の保護画面アクセスはログイン画面へ遷移する。
4. 機能権限不足は 403 ページを表示する。
5. 存在しない URL は 404 ページを表示する。
6. 未処理例外は 500 ページを表示する。
7. 用語表示は 99_用語集 の定義に合わせる。

## 4. 画面遷移要件
1. SCR-01 ログイン成功時に SCR-02 へ遷移する。
2. SCR-02 のテーマクリックで SCR-04 へ遷移する。
3. SCR-02 の勉強会作成選択で SCR-03 へ遷移する。
4. SCR-03 登録成功時に SCR-02 へ遷移する。
5. SCR-04 パンくずまたはキャンセルで SCR-02 へ戻る。
6. ログアウト操作時は SCR-01 へ遷移する。

## 5. 画面別要件

### 5.1 SCR-01 ログイン画面
| 項目 | 要件 |
|---|---|
| 入力項目 | ログインID、パスワード |
| 必須 | ログインID、パスワードは必須 |
| 入力制約 | ログインIDは1〜64文字、パスワードは1文字以上 |
| 操作 | ログインボタン押下で認証処理 |
| 正常時 | 認証 Cookie を発行し SCR-02 へ遷移 |
| 異常時 | 画面遷移せず、画面上部にエラーメッセージ表示 |

ログイン失敗メッセージ要件:
1. 表示文言は「ログインIDまたはパスワードが正しくありません。」とする。
2. ユーザー存在有無はメッセージから推測できない文言にする。
3. 入力済みのログインIDは保持し、パスワードは再入力とする。

### 5.2 SCR-02 勉強会一覧画面
| 項目 | 要件 |
|---|---|
| 表示列 | 開催日時、勉強会テーマ、対面枠、リモート枠、あなたの出欠 |
| 検索 | キーワードと技術タグで絞込可能 |
| 状態表示 | 参加ステータスをバッジで表示 |
| 空き状況 | x/y 名表示。満席時は満席表示 |
| 開催形式 | 非対象枠は「- (対象外)」表示 |

参加ステータス表示:
1. Unanswered は未回答表示。
2. Onsite は対面出席表示。
3. Remote はリモート出席表示。
4. Absent は欠席表示。

### 5.3 SCR-03 勉強会作成画面
入力項目:
| 項目 | 必須 | 制約 |
|---|---|---|
| 勉強会テーマ | Yes | 1〜200文字 |
| 開始日時 | Yes | 現在以降 |
| 終了日時 | Yes | 開始日時より後 |
| 開催形式 | Yes | Hybrid/OnsiteOnly/RemoteOnly |
| 対面枠定員 | Yes | 0〜200 |
| リモート枠定員 | Yes | 0〜500 |
| 概要 | No | 0〜2000文字 |

検証ルール:
1. format=OnsiteOnly の場合、リモート枠は 0 必須。
2. format=RemoteOnly の場合、対面枠は 0 必須。
3. format=Hybrid の場合、対面枠とリモート枠は 1 以上。
4. 入力不備時は項目単位でエラーメッセージを表示し保存しない。

### 5.4 SCR-04 勉強会詳細画面
表示項目:
1. パンくず。
2. 勉強会タイトル。
3. 概要。
4. 開催形式。
5. 開催日時。
6. 出欠変更締切メッセージ。
7. 参加申込フォーム。
8. 参加者名簿。

参加申込フォーム要件:
| 項目 | 要件 |
|---|---|
| 参加ステータス | Unanswered/Onsite/Remote/Absent |
| コメント | 任意、0〜500文字 |
| 更新ボタン | 入力検証後に保存 |
| キャンセル | 変更を破棄し再表示 |

業務ルール:
1. 開催形式が OnsiteOnly の場合、Remote 選択肢を無効化する。
2. 開催形式が RemoteOnly の場合、Onsite 選択肢を無効化する。
3. 出欠変更締切は開催前日 18:00 とする。
4. 定員超過時は Onsite/Remote への更新を拒否する。

参加者名簿要件:
1. 表示列は ユーザーID、氏名、出欠・参加ステータス、コメント。
2. 欠席者は視認可能な状態表示を行う。

### 5.5 SCR-05 403エラー画面
1. 権限不足を明示する。
2. 一覧画面へ戻る導線を提供する。
3. システム内部情報は表示しない。

### 5.6 SCR-06 404エラー画面
1. ページが存在しないことを明示する。
2. 一覧画面へ戻る導線を提供する。

### 5.7 SCR-07 500エラー画面
1. 一時的障害である旨を表示する。
2. 再試行または一覧画面へ戻る導線を提供する。
3. 例外詳細は利用者へ表示しない。

## 6. 入力エラーメッセージ方針
1. 日本語で表示し、原因と対処を短く示す。
2. 業務ルール違反は該当項目直下へ表示する。
3. 複数エラー時はサマリーと項目エラーを併用する。

## 7. セキュリティ要件（画面観点）
1. フォーム入力はサーバー側で再検証する。
2. CSRF 対策を適用する。
3. 出力エスケープで XSS を防止する。
4. 認証 Cookie は HttpOnly/Secure/SameSite を有効化する。

## 8. アクセシビリティ要件
1. キーボード操作で主要操作を完結できること。
2. 入力項目にラベルを関連付けること。
3. スキップリンクを提供すること。
4. ステータス表示は色だけに依存しないこと。
