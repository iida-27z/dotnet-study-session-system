# 99_用語集

## 1. 目的
本ドキュメントは、社内勉強会管理システムで利用するドメイン用語の定義をまとめる。
他の specs は本用語集を正本として参照し、同義語の乱立を防ぐ。

## 2. 用語一覧
| 用語 | 英語表記 | 定義 | 備考 |
|---|---|---|---|
| 勉強会セッション | Study Session | テーマ、開催日時、開催形式、定員を持つ社内勉強会の開催単位。 | 一般に「勉強会」と略記する。 |
| 開催形式 | Session Format | 勉強会セッションの開催方法。対面のみ、リモートのみ、ハイブリッドの3種。 | 値は system enum として管理する。 |
| 対面枠 | Onsite Capacity | 対面参加の受け入れ定員。 | 0 の場合は対面非対応。 |
| リモート枠 | Remote Capacity | リモート参加の受け入れ定員。 | 0 の場合はリモート非対応。 |
| 参加ステータス | Attendance Status | ユーザーごとの出欠状態。未回答、対面出席、リモート出席、欠席の4種。 | ステータス遷移は 04_Webアプリ機能要件 を参照。 |
| 主催者 | Organizer | 勉強会セッションを作成したユーザー。 | 初版は専用ロールを持たず、作成行為で決定する。 |
| ユーザー | User | システムを利用する社内社員アカウント。 | ロールとしての User を含む。 |
| 管理者 | Admin | 運用管理を担うユーザー。 | ロール値は Admin。 |
| ログインID | Login ID | ユーザー認証に使用する一意の識別子。 | users.login_id に保存する。 |
| 初期パスワード | Initial Password | ユーザー登録時に設定する初回利用パスワード。 | DBには平文で保存しない。 |
| パスワードハッシュ | Password Hash | 初期パスワードまたは変更後パスワードをハッシュ化した値。 | bcrypt で生成・検証する。 |
| 認証Cookie | Authentication Cookie | ログイン後に発行する認証セッション情報。 | Secure/HttpOnly/SameSite を有効化。 |
| ユーザー登録バッチ | User Registration Batch | 手動実行コンソールでユーザー登録を行う処理。 | 単件入力と CSV 一括取込に対応。 |
| 監査ログ | Audit Log | 重要操作を追跡するための記録。 | ログイン、勉強会作成、出欠更新、バッチ実行などを対象とする。 |

## 3. ルール
1. 新しい業務用語を追加する場合は、先に本ファイルを更新する。
2. 既存用語を変更する場合は、影響する specs の参照箇所を同時更新する。
3. 実装コード上の列挙値やテーブル名は、本用語集と 03_データモデル・DB要件 の定義に一致させる。
